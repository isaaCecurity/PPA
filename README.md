# PPA — Strategic Cybersecurity Outreach

This repository manages a deliberate, multi-channel campaign to secure a cybersecurity-focused NYSC/PPA or internship placement.

## Repository structure

- `Lagos_NYSC_Cybersecurity_Target_Companies_Research.xlsx` — master research and outreach tracker.
- `00_PROJECT/` — project status, rules and operating sequence.
- `02_COMPANIES/` — one workspace per target company. Each active company is organized into research, contacts, LinkedIn, email, resume and activity-log areas.

## Outreach model

**Research → LinkedIn warm-up → connection → personalized DM → tailored email/CV → follow-up → justified escalation.**

LinkedIn is a core channel. Email is not automatically the first contact. A technical/security contact and a Talent/HR contact are targeted separately so the campaign can develop both a potential technical sponsor and a recruitment route.
