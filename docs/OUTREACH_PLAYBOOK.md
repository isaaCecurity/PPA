# PPA Strategic Outreach Playbook

1. Identify two humans: Security/IT decision-maker + Talent/HR.
2. Warm up naturally on LinkedIn.
3. Send a short connection note.
4. Send a short PPA DM asking who handles NYSC/PPA placements.
5. Send a tailored email + CV.
6. Apply to matching vacancies.
7. Follow up after 5–7 business days.
8. Escalate only when justified.

Use a maximum of 2–3 contacts per company. Generic inboxes are fallback routes. The first wave should use draft/review-first sending. LinkedIn actions are only marked sent when the connected capability confirms the action.

`STARTPPA` means: read the tracker, search Gmail for relevant replies, classify responses, update statuses, calculate next actions, and report material changes.
